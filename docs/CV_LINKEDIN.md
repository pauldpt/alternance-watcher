## Version LinkedIn

Je viens de construire un pipeline automatise de veille d'alternances oriente Cloud/Data/DevOps.

Le projet interroge l'API La Bonne Alternance, score les offres selon mon profil cible et mon niveau Bac+3/BUT3, priorise les entreprises strategiques, evite les doublons, stocke l'historique dans une base SQL et envoie les nouvelles opportunites sur Discord via webhook.

Stack:

- Python
- GitHub Actions
- PostgreSQL/Supabase
- Discord Webhooks
- API ingestion
- Scoring metier
- Priorisation d'opportunites
- Deduplication
- Markdown/CSV reporting

Objectif: transformer un besoin reel de recherche d'alternance en projet concret de data/cloud automation.

## Pitch oral

J'ai construit un pipeline qui surveille automatiquement les offres d'alternance pertinentes pour un profil Cloud/Data/DevOps Bac+3/BUT3. Le systeme recupere les offres via API, applique un scoring, priorise les entreprises ciblees, evite les doublons, stocke l'historique en base et envoie les nouvelles offres dans Discord. Le projet tourne en local avec SQLite ou en cloud avec GitHub Actions et Supabase.
